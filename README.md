# Order System — Laravel Application

A clean, simple Laravel application where a user can **place an order** and the order is **saved to the database**. Built with Laravel 13, Eloquent ORM, and MySQL, following proper MVC architecture with server-side validation.

**Live Demo:** [https://order-system.luxuryloverpro.com](https://order-system.luxuryloverpro.com)
**Repository:** [https://github.com/ShakilJoy31/order-system-php-app](https://github.com/ShakilJoy31/order-system-php-app)

---

## ✨ Features

- **Place an order** via a clean, styled form
- **Server-side validation** with friendly error messages
- **Save to MySQL** using Eloquent ORM
- **Success flash messages** after submission
- **Recent Orders** list showing all orders (newest first)
- **Empty state** when no orders exist yet
- **Form input preservation** — if validation fails, the user's values are retained
- **Responsive UI** with Tailwind CSS via CDN
